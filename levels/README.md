# Уровни Sokoban

Все 101 карта лежат по одной в XSB-файле и разделены по ручным категориям в папке [`library`](library): `easy`, `medium`, `hard` и `very-hard`. Папка файла является единственным источником сложности уровня.

[`locations.json`](locations.json) задаёт 16 игровых локаций, их карточки, фон, звук и порядок карт внутри каждой главы. Чтобы перенести уровень или изменить порядок кнопок слева направо, достаточно переставить его `id` в массивах `levelIds`. Каждый `id` должен встречаться ровно один раз.

Оформление также разделено по локациям в папке [`appearance`](appearance). После переноса карты старое оформление игнорируется, а новое можно быстро назначить заливкой в редакторе. Игровые JSON в `src/game/gameConfig/levels/generated` создаются автоматически и вручную не редактируются.

Общая справка: [`docs/levels/overview.md`](../docs/levels/overview.md).

Дорожные карты:

- [добавление уровня в существующую карточку](../docs/levels/add-level-to-existing-card.md);
- [создание карточки локации и добавление в главы](../docs/levels/create-location-card.md).

Основные команды:

```bash
npm run levels
npm run levels:check
npm run levels:solve-pushes
```

`npm start` и `npm run build` обновляют игровые JSON автоматически, но не запускают длительный поиск эталонных решений. `npm run levels:solve-pushes` запускается отдельно только после добавления или изменения карт.
