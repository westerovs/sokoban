# Уровни Sokoban

Канонический формат проекта — стандартный XSB. Он понятен большинству решателей Sokoban и не зависит от внутренних обозначений игры.

## Структура

- `packs/project.xsb` — 11 уровней, которые уже были в игре. Их порядок и стабильные `id` сохранены.
- `packs/xsokoban-90.xsb` — классический набор из 90 карт в исходном порядке.
- `metadata/xsokoban-90-solver-stats.json` — результаты проверки Takaken 7.3.1.
- `catalog.json` — порядок пакетов и правила их сборки.
- `solver/all-levels.xsb` — автоматически собранный файл всех уровней в порядке игры.
- `src/game/gameConfig/levels.json` — автоматически собранный формат, который загружает игра.

## Как добавить уровни

1. Добавьте новый `.xsb` в `levels/packs` или допишите карту в существующий пакет.
2. Зарегистрируйте пакет в `levels/catalog.json`.
3. Выполните `npm run levels`.
4. Откройте `levels/solver/all-levels.xsb` в решателе и прогоните весь набор.

Обычные `npm start` и `npm run build` выполняют генерацию автоматически.

## Обозначения XSB

| Символ | Значение |
| --- | --- |
| `#` | стена |
| пробел | пол |
| `@` | игрок |
| `$` | ящик |
| `.` | цель |
| `*` | ящик на цели |
| `+` | игрок на цели |

Карты разделяются пустой строкой. Перед картой можно указывать метаданные комментариями вида `; id: sokoban-01` и `; source-level: 38`.

## Порядок сложности

Сначала всегда идут 11 проектных карт без перестановки. Следующие 90 карт сортируются по оценке:

`толчки + ходы × 0.15 + ящики × 4 + log2(время + 1) × 20`

Оценка нужна только для относительного порядка внутри классического набора. Первые 30 карт получают категорию `easy`, следующие 30 — `medium`, последние 30 — `hard`. Это воспроизводимая практическая эвристика, а не математическая гарантия субъективной сложности для каждого игрока.

Поле `pushRecord` добавляется в игровой JSON только тогда, когда лучший опубликованный результат по толчкам совпадает с доказанной нижней границей. Сейчас такой минимум известен для 4 из 90 классических карт; только на них нижний HUD показывает «Рекорд».

## Проверка решателем

Для 89 классических карт сохранено точное совпадение карты с опубликованным прогоном Takaken 7.3.1. Отсутствующая в таблице карта №77 отдельно решена официальной командной версией Takaken 7.3: 421 ход и 174 толчка. Её LURD-решение хранится в метаданных и автоматически переигрывается при каждой генерации.

Проектные 11 карт находятся в общем XSB-файле, но не получают отметку `verified`, пока вы не прогоните их своим решателем.

Если выбранный решатель не понимает строки, начинающиеся с `;`, удалите только эти строки — сами карты останутся стандартным XSB.
