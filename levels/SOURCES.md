# Источники уровней

## Project

Первые 11 карт перенесены из существующего `src/game/gameConfig/levels.json`. Их происхождение этим изменением не переопределяется.

## XSokoban 90

- Файл: `data/sokoban/levels/default.txt` из репозитория <https://github.com/davidjoffe/sokoban>.
- Автор репозитория указывает, что стандартные 90 уровней являются public domain. Юридическая история карт независимо не проверялась, поэтому ссылка на источник сохранена рядом с данными.
- Решаемость: <https://sokoban-solver-statistics.sourceforge.io/statistics/OpenTestSuiteMultipleVersions/Takaken%207.3.1%20-%20XSokoban.html>.
- 89 карт побайтно-независимо сопоставлены с опубликованным прогоном через нормализованный SHA-256. Карта №53 исходного файла соответствует карте №77 в таблице решателя.
- Карта №77 исходного файла отсутствует в опубликованном наборе вместо неё там повторяется другая карта. Она отдельно решена официальной командной версией Takaken 7.3: <https://computerpuzzle.net/english/sokoban/ver730/cmd.html>.
- Итог: у всех 90 импортированных карт есть подтверждение решения; лимит решателя составлял 600 секунд на карту.
