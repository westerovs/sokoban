# Модальные окна и fade

Все обычные модалки открываются в единственном [`ModalLayer`](../src/game/engine/uiLayer/ModalLayer.ts). Слой постоянно существует внутри `UiLayer`, но становится видимым только вместе с модальным окном.

```text
modalLayer
├─ modalFade
└─ activeModal
```

`modalFade` всегда находится перед остальным интерфейсом и позади активной модалки. Поэтому он затемняет фон, UI текущего стейта, постоянную шестерёнку и отладочные элементы.

FadeOverlay имеет интерактивный режим и не пропускает нажатия к интерфейсу под модалкой.

Одновременно может быть открыта только одна модалка. Попытка открыть другую вернёт `false`.

## Обычная модалка через BaseModal

Предпочтительный способ — наследование от [`BaseModal`](../src/game/ui/common/modal/BaseModal.js). Он уже умеет:

- открывать окно через `UiLayer.openModal()`;
- показывать общий fade;
- адаптировать окно;
- закрываться по крестику, клику снаружи и `Escape`;
- убирать окно из `modalLayer`;
- уничтожать окно и его дочерние элементы.

```js
import BaseModal from '@/game/components/modal/BaseModal.js'

export default class HelpModal extends BaseModal {
  constructor() {
    super({
      label: 'helpModal',
      w: 600,
      h: 500,
      isNeedHeader: true,
    })

    this.#init()
  }

  #init = () => {
    this.headerText.text = 'Помощь'
    this.#createContent()
  }
}
```

Открытие:

```js
const modal = new HelpModal()
await modal.show()
```

Закрытие из контроллера:

```js
await modal.hide()
```

Не добавляйте такую модалку вручную в `stateUiLayer`, `globalUiLayer` или `modalLayer`. Не создавайте для неё отдельный fade. Всё это выполняет `BaseModal.show()`.

После `hide()` обычная `BaseModal` уничтожается и не должна использоваться повторно. Для следующего открытия создайте новый экземпляр.

## Постоянная переиспользуемая модалка

Если окно должно жить всю игру, как `OptionsView`, оно не должно уничтожаться при закрытии. Такое окно самостоятельно использует API `UiLayer`:

```js
open = () => {
  if (!Locator.uiLayer.openModal(this)) return false

  this.visible = true
  return true
}

close = () => {
  this.visible = false
  Locator.uiLayer.closeModal(this)
}
```

Правила:

- открывать окно только после успешного `openModal()`;
- при закрытии обязательно передавать тот же экземпляр в `closeModal()`;
- снять собственные события и вызвать `closeModal()` перед окончательным `destroy()`;
- не уничтожать постоянный экземпляр при обычном закрытии.

`closeModal(view)` безопасно закроет слой только тогда, когда `view` является текущей активной модалкой. Передача другого объекта ничего не изменит.

## Адаптивность модалки

`openModal()` сразу вызывает `resizeAdaptive(view)`. `UiLayer` передаёт окно в `AdaptiveLayout`. Для стандартной адаптивной позиции у окна должны быть `label` и публичный `updateAdaptive`; при необходимости позицию можно уточнить через `_customPosition`.

У `BaseModal` этот метод уже существует, поэтому при `show()` дополнительный вызов resize не нужен.

Подробнее: [Адаптивный UI](adaptive-ui.md).

## Очистка

### Обычная BaseModal

Используйте `await modal.hide()`. Последовательность уже реализована:

1. Отключаются события модалки.
2. Проигрывается анимация скрытия.
3. Вызывается `closeModal(this)`.
4. Модалка уничтожается вместе с дочерними элементами.

Прямой `destroy()` также освобождает `modalLayer`, но для пользовательского закрытия предпочтителен `hide()`, чтобы сохранить анимацию и звук.

### Постоянная модалка

Скройте окно и вызовите `closeModal(this)`. После этого общий fade выключится, а `modalLayer` снова станет невидимым.

## Два разных вида fade

Не путайте модальный fade с методами `UiLayer.createFade()` и `UiLayer.destroyFade()`.

- `modalFade` принадлежит `modalLayer` и управляется через `openModal()`/`closeModal()`.
- `createFade()` создаёт временный fade внутри `stateUiLayer` для обучения, масок и подсветки отдельных областей.

Для обычных попапов `createFade()` вызывать не нужно. Временный state-fade следует удалять через:

```js
Locator.uiLayer.destroyFade()
```

Он также автоматически удаляется при `destroyStateUiLayerChildren()` во время смены стейта.

## Типичные ошибки

- Добавлять модалку в `stateUiLayer`, а fade создавать отдельно.
- Хранить собственный модальный fade в каждом окне.
- Уничтожать `modalLayer` после закрытия окна.
- Забывать вызвать `closeModal()` у постоянной модалки.
- Открывать вторую модалку, не закрыв первую.
- Продолжать использовать экземпляр `BaseModal` после `hide()`.
