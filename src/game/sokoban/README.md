# Модуль Sokoban

Файлы разложены по ответственности, чтобы игровая логика не смешивалась с PixiJS-представлением и инструментами редактора:

- `config/` — символы карты, текстуры и настраиваемые параметры;
- `editor/` — открытие редактора, выбор уровня из URL и применение черновика;
- `gameplay/` — состояние уровня и координация игровой сессии;
- `input/` — клавиатура, свайпы и экранная крестовина;
- `rendering/` — игровая доска, ящики и масштабирование тайлов;
- `ui/` — HUD и его кнопки.

Внешний код должен импортировать конкретный файл из соответствующего слоя. Общего индексного реэкспорта нет, чтобы зависимости оставались явными.
